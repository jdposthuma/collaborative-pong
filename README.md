# Collaborative Pong

A React-based implementation of Pong with a collaborative twist. Players work together to reveal hidden images by bouncing the ball across the screen.

## Getting started
```bash
npm install
npm start
```

## Controls
- Player 1 (Left): W/S keys
- Player 2 (Right): Up/Down arrow keys
- Space: Start/Pause game

## Deploy
Automatically deployed to Github pages on push.
